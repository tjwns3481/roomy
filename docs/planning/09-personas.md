# 09-personas.md
## 사용자 페르소나

### 개요
Roomy의 핵심 사용자 2명을 구체적으로 정의한다. "만약 이 두 명이 Roomy를 5분 만에 사용한다면 성공"이라는 기준으로 모든 결정을 내린다.

## 페르소나 1: 지현 (부업 호스트)

### 한 줄 정의
30대 직장인, 에어비앤비로 부업 중, 반복 질문에 시달리는 호스트.

### 기본 정보

| 항목 | 내용 |
|-----|------|
| **이름** | 지현 (가명) |
| **성별** | 여성 |
| **나이** | 34세 |
| **직업** | 회사원 (마케팅팀) |
| **지역** | 서울 강남구 |
| **가구** | 기혼, 자녀 1명 |
| **월소득** | 약 600만원 (본업) + 부업 월평균 300만원 |

### 심리 프로필

**성격**
- 효율성 중시
- 행동력 있음
- 세심함 (게스트 만족도 신경 씀)
- 밤잠을 설치기 싫어함

**가치관**
- 일과 삶의 균형 (일-라이프 밸런스)
- 자동화로 시간 절약
- 게스트 만족도는 높게 유지하고 싶음

**현재 상황**
- 에어비앤비 1채, Airbnb 2채 운영
- 월 예약률: 70~80%
- 월 매출: 약 300만원 (순이익)
- 새 예약이 들어올 때마다 메시지 폭주

### 고객 journey: "새벽 2시 도어락 질문"

#### 단계 1: 예약 확정 (오후 7시)
- **상황**: 퇴근 후 집에서 저녁 먹을 때, 에어비앤비 앱에 새 예약 알림
- **감정**: 좋음 (매출 증가). 조금 귀찮음 (설명 또 해야지)
- **액션**: 즉시 메시지로 안내 시작
  ```
  "안녕하세요! 예약 감사합니다.
  1. 도어락 비번: 1234*
  2. 와이파이: SSID / 비번: ****
  3. 체크인은 17시 이후...
  (복사-붙여넣기 같은 내용)
  ```

#### 단계 2: 게스트 질문 들어오기 (밤 10시)
- **상황**: 자기 준비 중. 게스트로부터 메시지: "도어락 비번이 뭐였죠?"
- **감정**: 답답함. "방금 보낸 메시지를 안 봤네?"
- **액션**: 다시 한 번 도어락 비번 전송

#### 단계 3: 새벽 2시의 악몽
- **상황**: 깊은 잠에서 휴대폰 울림. 게스트: "도어락이 안 돼요ㅠ 지금 현관에 있는데 어떻게 합니까?"
- **감정**: 매우 짜증남. 자고 싶은데 깬 것도 싫고, 게스트 문제 해결도 귀찮음
- **액션**: 다시 전화로 설명. 30분 소비.
- **결과**: 자려던 시간 낭비, 다음날 업무 피로

#### 단계 4: 반복 (매달)
- **매달 새 게스트 3~4명마다** 비슷한 상황 반복
- **누적**: 월 10시간 이상 카톡 응대 시간 소비
- **느낌**: "이 일을 어떻게 줄일 수 없을까?"

### 니즈 (Unmet Needs)

**명시적 니즈**
1. 도어락, 와이파이, 체크인 안내를 한 번에 보낸다
2. 게스트가 알아서 보도록 한다
3. 반복적인 질문을 줄인다

**숨은 니즈**
1. 밤과 근무 시간에 방해받지 않는다
2. 게스트는 여전히 충분히 안내받는다 (만족도 유지)
3. 호스트로서의 프로페셔널함 유지 (투박한 카톡이 아님)
4. 호스트 신뢰도 상승 (게스트가 "와, 이 숙소는 다르네" 느낌)

### 구매 결정 요소

**꼭 필요한 조건**
- 5분 안에 만든다 (바쁠 때도 빨리 만들고 싶음)
- 도어락, 와이파이, 체크인 3개 섹션 필수 (이것만으로 80% 질문 해결)
- URL 공유 가능 (카톡, SNS)

**있으면 좋은 조건**
- 조회 통계 (게스트가 봤는지 확인)
- 편한 수정 (다음 숙소는 내용만 바꾸고 재사용)
- 예쁜 디자인 (게스트에게 좋은 인상)

**가격 수용 범위**
- 최대 ₩50,000 (한 달 부업 수익의 20% 미만)
- 일회성 구매 선호 (매달 구독은 싫음)
- 오래 쓸 수 있으면 가격 정당화

### 사용 시나리오: 예약 들어온 당일

```
시간: 오후 7시 30분 (퇴근 후)
상황: 스마트폰으로 Roomy 링크 클릭
걸리는 시간: 정확히 5분

1분 00초: Roomy 랜딩 페이지
         → "이거 뭐지? 예쁘긴 한데..."
         
1분 30초: "템플릿 구경하기" 클릭
         → 갤러리 진입 (객실 안내서 탭)

2분 00초: "미니멀 객실 가이드" 템플릿 선택
         → 데모 페이지에서 스크롤 (30초 감상)
         
2분 30초: "이 템플릿으로 만들기" 클릭
         → 에디터 진입

3분 00초: 제목: "501호 객실 가이드" 입력
         
3분 30초: 폼 채우기
         - 도어락: 1234* (복사-붙여넣기)
         - 와이파이: SSID / 비번
         - 체크인: "4시 이후 도착 부탁합니다"
         
4분 00초: 대표 사진 2장 선택 (기존 폴더에서)
         
4분 30초: "계속하기" → 결제

5분 00초: 결제 완료
         → URL 발급: https://roomy.app/page/501-guide-2026
         
5분 30초: "카톡으로 공유하기" 클릭
         → 카톡 앱 열림 (URL 자동 입력)
         → 게스트에게 메시지 전송

**결과**: 게스트가 받은 카톡
```
안녕하세요! 예약 감사합니다 😊
여기 우리 숙소 안내입니다 → https://roomy.app/page/501-guide-2026
이 페이지에 필요한 모든 정보가 있어요!

→ 게스트가 링크 클릭
→ 아름다운 페이지에 도어락, 와이파이, 체크인 안내 정렬
→ 더 이상 반복 질문 안 함
```

### 기대 효과

**행동 변화**
- 새벽 2시 도어락 질문에 깬 횟수: 월 1~2회 → 0회
- 카톡 응대 시간: 월 10시간 → 월 1시간 (페이지 수정만)
- 게스트 만족도: 유지 또는 상승 (투박한 안내 → 예쁜 페이지)

**심리 변화**
- "이제 밤 10시에는 핸드폰 꺼도 된다"
- "게스트가 페이지를 봤으면 충분히 알겠지"
- "호스트로서 전문적이다는 느낌"
- "이것도 마케팅이 되나? 게스트가 사진 찍어서 SNS에 올리네"

## 페르소나 2: 수진·민준 (예비부부)

### 한 줄 정의
신혼부부 예비자, 디자인 감성 중시, 모바일 청첩장으로 새로운 결혼식 경험 원함.

### 기본 정보

| 항목 | 신부 수진 | 신랑 민준 |
|-----|---------|---------|
| **나이** | 29세 | 31세 |
| **직업** | 광고회사 AE | IT 회사 엔지니어 |
| **지역** | 서울 마포구 | 서울 서초구 |
| **월소득** | 약 450만원 | 약 550만원 |
| **결혼 예정일** | 2026년 10월 (4개월 후) | - |
| **성향** | 감성적, 감각 있음 | 논리적, 기술 관심 많음 |

### 심리 프로필

**수진 성격**
- 감성적, 감각 있음 (옷, 카페, 인테리어 관심)
- SNS 활동 적극적 (인스타 팔로워 3,000명)
- 완벽주의 (결혼식 모든 디테일 신경 씀)
- 비용 의식 (백만 원 이상은 신중함)

**민준 성격**
- 논리적, 효율성 중시
- 기술 관심 많음 (새로운 도구 빨리 배움)
- 실용적 (결혼식 비용 효율화 고민)
- 모바일 친화적 (PC보다 핸드폰 중심)

**공통 가치관**
- 결혼식은 "개성 있게" (일반적인 결혼식과 다르게)
- 게스트들에게 "좋은 인상" (감각 있는 커플 이미지)
- 참석 비용 최소화 (청첩 인쇄비, 택배비 없음)
- 편리함 (관리 간단함, 수정 쉬움)

### 고객 journey: "결혼 준비 2개월 전"

#### 단계 1: 결혼식 형태 결정 (8월)
- **상황**: 신혼집 계약 후 결혼식 계획 시작
- **수진 생각**: "모바일 청첩장만으로 하고 싶어. 인쇄는 환경에도 안 좋고"
- **민준 생각**: "좋아, 그럼 그걸로 하자. 비용도 절약되고"
- **공동 결정**: "모바일 청첩장 + 택배 인쇄본은 50장만"

#### 단계 2: 기존 업체 시도 (8월 말)
- **상황**: 인스타그램 "#모바일청첩장" 검색 → 바른손, 디어달리아 발견
- **행동**: 바른손 템플릿 직접 구성해봄 (2시간 소비)
- **감정**: 
  - 수진: "이건 너무 평범해. 다들 이런 거랑 비슷한데? 뭔가 더 세련되면 좋겠는데"
  - 민준: "UI가 복잡한데? 여기저기 클릭해야 하고... 2시간 걸렸다고?"
- **결과**: "이건 아닌 것 같은데..." (불만족)

#### 단계 3: 감성 있는 거 찾기 (9월 초)
- **상황**: 결혼준비 카페, Pinterest, TikTok에서 "감성 모바일 청첩장" 검색
- **발견**: "Roomy" 광고 또는 입소문
  ```
  카페 댓글: "Roomy라는 새로운 거 써봤는데 진짜 예쁘다!"
  Pinterest: "5분 만에 완성되는 세련된 모바일 청첩장"
  ```
- **클릭**: Roomy 랜딩 페이지 방문
- **감정**: 
  - 수진: "오... 이거 예쁜데? 배경음악도 부드럽고 폰트가 세련됐다"
  - 민준: "빠르네. 템플릿도 깔끔하고"

#### 단계 4: Roomy로 제작 (9월 중)
- **시간**: 토요일 오후 2시간
- **과정**:
  1. 갤러리에서 "세련된 핑크" 템플릿 선택 (1분)
  2. 에디터에서:
     - 신랑·신부 이름 입력 (1분)
     - 결혼식 일시 입력 (1분)
     - 대표 사진 2장 업로드 (3분, 드래그앤드롭 직관적)
     - 스토리 텍스트 작성 (10분, 손으로 쓴 느낌)
     - 축의금 계좌 입력 (2분)
     - 오시는 길 주소 입력 (1분, 주소 검색 자동)
     - 색상 조정: 주 색상을 로즈골드로 변경 (2분)
     - 미리보기 감상 (20분, 흐뭇해하며)
  3. 결제 (1분, 카카오 페이)
  4. URL 받음: https://roomy.app/page/sujin-minjun-2026
  5. 카톡으로 부모님, 친구들에게 공유

#### 단계 5: 공유 & 입소문 (9월 말 ~ 10월)
- **행동**:
  - 카톡 단톡방에 URL 공유
  - 인스타그램 스토리에 게시 (스크린샷 + URL)
  - Pinterest에 올림 (좋아요 500개 이상)
  - 결혼준비 카페에 후기 글 작성
- **반응**:
  - 친구 1: "우와, 이거 진짜 예쁜데? 우리도 할까?"
  - 친구 2: "뭐 이 앱? 우리 청첩장 도 다시 만들어야겠다"
  - 친구 3: "이거 비용이 얼마여?"
- **부작용**: 수진의 친구 3명이 Roomy 가입 (입소문)

#### 단계 6: 수정 & 최종 완성 (10월 초)
- **수정 사항**:
  - 날씨 아이콘 추가 (사진 더 넣고 싶음)
  - 방명록 섹션 추가 (하객이 축하 메시지 남기도록)
  - 색상을 분홍에서 주황으로 변경 (민준 제안)
- **마이페이지에서** 기존 페이지 수정
  - 에디터로 진입 (재작업 시간 < 10분)
  - URL 유지 (공유된 링크 그대로)
- **결과**: 최종 완성본 공개

### 니즈

**명시적 니즈**
1. 모바일 청첩장이 "예쁘다"는 말을 들으려고
2. 5분 안에 완성 (너무 복잡하지 않으면서)
3. SNS에 자랑할 만한 수준 (입소문 가능)
4. 나중에 수정 쉬움 (새로운 정보 추가)

**숨은 니즈**
1. 결혼 준비 과정이 "감각 있다"는 느낌
2. 게스트들이 "이 커플은 다르네" 인상
3. 비용 효율 (인쇄 비용 대비 훨씬 저렴)
4. SNS에서 자랑 가능 (남편이 IT 일하는 거 자랑처럼, 아내는 감성적 선택 자랑)
5. 참석 여부를 쉽게 받음 (RSVP 기능)

- 템플릿이 "예쁘다" (기존 업체보다 세련됨)

**신뢰도**
- 받는 사람의 모바일에서 예쁘게 로드
- URL 공유 가능 (카톡, 인스타 OK)
- 1년 유지 (결혼 후 몇 개월는 열어볼 수 있음)

## 페르소나 활용 원칙

### 모든 결정의 필터

```
"이 기능/디자인이 지현이나 수진·민준을 만족시킬까?"

예:
- RSVP 기능을 추가할까? → 수진이는 "참석 여부 받으려고" YES
- 어두운 색상 템플릿 추가? → 둘 다 "감성적"이라고 느끼나? 아니면 YES
- 블록 조립 기능 추가? → 지현이 "5분 안에 만들 수 있나?" 아니면 NO
- 다국어 자동 번역? → 첫 출시엔 필요 없음 (한국 시장만 집중)
```

### 피해야 할 것

| 반면 | 이유 | 페르소나 영향 |
|-----|------|-------------|
| 복잡한 기능 | 지현이가 5분 안에 못 만듦 | 지현 이탈 |
| 투박한 디자인 | 수진이가 "이건 아니다"고 판단 | 수진·민준 이탈 |
| 느린 로딩 | 모두가 "이게 최신 앱인가?" 의심 | 신뢰도 하락 |
| 반복적인 설명 | 지현이 "매번 이 과정이?" 피로 | 반복 사용 율 떨어짐 |
| 수정 불가능 | 수진이가 "아, 잘못했네" 할 때 대응 불가 | 고객 만족도 최악 |
