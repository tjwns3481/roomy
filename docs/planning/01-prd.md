## 제품 요구사항

### 프로젝트명
Roomy

### 한 줄 정의
감성 디자인 템플릿을 고객이 직접 꾸미고, 만족하면 구매해서, 링크로 공유하는 모바일 페이지 SaaS.

---

## 문제 정의의 변화

### 처음 요청
숙박 호스트가 매번 새로운 게스트에게 똑같은 내용(와이파이 비번, 도어락, 체크인 방법)을 설명하는 반복 업무를 덜어주는 "객실 안내서 도구"가 필요하다.

### 재정의
감성 디자인과 부드러운 인터랙션이 핵심이다. 사용자는 "기능"이 아니라 "보는 것만으로도 예쁜 페이지"를 원한다. 따라서 커스텀 가능한 디자인 템플릿 2종(객실 안내서 + 모바일 청첩장)을 고객이 직접 꾸며서 구매하고, 공유할 수 있는 모바일 SaaS로 확대한다.

### 왜 달라졌나
소크라테스 인터뷰 과정에서 사용자가 명시적으로 "완성형 프로덕트"를 원한다고 했다. 즉, 기능 먼저가 아니라 감성·디자인·Toss 같은 부드러운 사용감(마이크로 인터랙션, 모션)을 최우선 가치로 봤을 때 시장이 더 크다는 판단.

---

## 문제 상황 (구체 장면)

**호스트 지현, 새벽 2시**
- 새 예약 확정 메시지가 온다.
- 게스트로부터 "도어락 비번이 뭐예요?", "와이파이는?", "체크인 어디서?" 메시지가 매일 반복된다.
- 자려는데 깨어서 메신저를 켜야 한다.
- 안내문을 메모장에 복사-붙여넣기로 보낸다 (투박하고 비전문적).

**원하는 변화**
- "예쁘고 깔끔한 안내서 URL 하나"를 카톡으로 보낸다.
- 게스트가 알아서 보고 답한다.
- 새벽 메시지에 깨지 않아도 된다.

## 첫 출시 버전(MVP) 범위

| 카테고리 | 항목 | 설명 | 우선순위 |
|---------|------|------|---------|
| **꼭 넣을 것** | 템플릿 갤러리 | 청첩장/객실 안내서 탭, 감성 큐레이션 | P0 |
| **꼭 넣을 것** | 에디터 | 사진/텍스트/색상/섹션 on-off 수정, 실시간 모바일 미리보기 | P0 |
| **꼭 넣을 것** | 결제 시스템 | 모크 어댑터 (추후 토스페이먼츠) | P0 |
| **꼭 넣을 것** | URL 발급 + 카톡 공유 | OG 태그 최적화, 링크로 페이지 공유 | P0 |
| **꼭 넣을 것** | 인터랙티브 뷰어 | 제품의 본체. 스크롤 모션, 마이크로 인터랙션 | P0 |
| **꼭 넣을 것** | 청첩장 필수 섹션 | 포토 갤러리(사진 슬라이드), 방명록, 참석여부 입력, 오시는길 지도, 축의금 계좌 복사 | P0 |
| **꼭 넣을 것** | 객실 안내서 필수 섹션 | 와이파이/도어락 카드, 체크인 가이드, 지도, 호스트 연락 버튼 | P0 |
| **꼭 넣을 것** | 무제한 수정 + URL 유지 | 구매 후 언제든 수정 가능, 발급된 URL은 유지 | P0 |
| **꼭 넣을 것** | 조회 통계 | 몇 명이 페이지를 봤는지 카운팅 | P0 |
| **있으면 좋은 것** | 카톡 알림톡 발송 | 손님이 페이지를 봤을 때 호스트에게 알림 | P1 |
| **있으면 좋은 것** | 템플릿 추가 카테고리 | 돌잔치, 행사 등 더 많은 버티컬 | P1 |
| **시간 남으면** | 다국어 자동 번역 | 외국인 게스트를 위한 자동 번역 | P2 |
| **이번 버전엔 뺄 것** | 예약 연동 자동 발송 | 에어비앤비 등과 API 연동해서 자동 발송 | Out |
| **이번 버전엔 뺄 것** | 블록 조립 자유 편집 | 사용자가 섹션을 자유롭게 조립하는 에디터 | Out |
| **이번 버전엔 뺄 것** | 호스트 대시보드 | 예약, 게스트 관리 등의 풀 BMS 기능 | Out |
| **이번 버전엔 뺄 것** | BGM(배경음악) | 저작권 관리·자동재생 정책 우려 | Out |

## 각 '꼭 넣을 것' 기능의 필수 이유

1. **템플릿 갤러리** → "첫 인상에서 '다르다'고 느껴야 경쟁사(노션 DIY, 카톡)와 다르다. 템플릿 선택 순간이 구매 결정의 60%."
2. **에디터** → "기술 비용 낮춰서 5분 안에 만든다. 높은 완성도 = 빠른 제작 = 누르게 되는 구매."
3. **결제 시스템** → "돈을 받아야 비즈니스다."
4. **URL 발급 + 카톡 공유** → "공유는 호스트의 최종 목적. OG 태그로 카톡 미리보기가 잘 떠야 클릭율 높다."
5. **인터랙티브 뷰어** → "Toss급 부드러운 사용감이 감성 디자인을 산다. 이게 없으면 그냥 예쁜 정적 페이지일 뿐."
6. **청첩장 필수 섹션** → "방명록, RSVP, 지도, 계좌 = 실제 청첩장이 갖춰야 할 최소 기능. 없으면 못 쓴다."
7. **객실 안내서 필수 섹션** → "와이파이, 도어락, 체크인, 연락처 = 게스트 질문 상위 4개. 이것만 해결해도 호스트 업무 80% 감소."
8. **무제한 수정 + URL 유지** → "공유 링크는 카톡, SNS에 퍼져야 한다. URL이 바뀌면 공유 가치가 0이 된다."
9. **조회 통계** → "몇 명이 봤는지 알아야 다음 버전 개선 동기가 생긴다. 호스트는 게스트가 페이지를 봤는지 궁금해한다."

## 성공 기준

| 지표 | 목표 | 측정 방법 |
|-----|------|---------|
| 첫 출시 사용자 수 | 5명 이상 (지인 호스트 + 결혼준비 커뮤니티) | 회원가입 수 |
| 제작 시간 퍼널 | 에디터 체류 / 인증 소요 / 결제 소요 구간별 측정 | GA 이벤트 추적 (단일 "5분" 지표 → 단계별 이탈률·전환율) |
| 뷰어 LCP | 2초 이내 | Lighthouse 측정 |
| 뷰어 모션 fps | 60fps 유지 | DevTools 프로파일 |
| URL 공유율 | 제작 완료자의 80% 이상 공유 | page_views 통계 |
| 디자인 감성 점수 | 받는 사람이 "예쁘다"고 평가 | 지인 피드백 |
| 반복 사용 의도 | 호스트 80%가 "다음번에도 쓸 것" 답변 | 사후 설문 |
