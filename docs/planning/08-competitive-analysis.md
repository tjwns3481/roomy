Roomy의 시장 경쟁자 3축을 분석하고, "낫다"의 근거를 정리한다.

## 경쟁자 1: Notion/카톡 DIY 안내문

### 특징

**장점**
- 완전 무료 (또는 무료 템플릿 많음)
- 관성이 강함 (이미 많은 사람이 사용)
- 설정 자유도 높음
- 설명 자료 많음 (YouTube 튜토리얼)

**단점**
- 디자인 감성 낮음 (다 비슷해 보임)
- 제작 시간 오래 걸림 (30분 이상)
- 모바일 UX 불편함 (복잡한 메뉴)
- 부드러운 인터랙션 없음 (정적)
- 받는 사람이 보는 페이지가 투박함
- 반복 사용 의도 낮음 (다음 숙소는 또 만들어야 함)

### Roomy의 우위

| 항목 | Notion/카톡 | Roomy | 우위 |
|-----|-----------|-------|------|
| 제작 시간 | 30분 이상 | 5분 | Roomy ⭐ |
| 디자인 감성 | 낮음 | 높음 | Roomy ⭐ |
| 부드러운 모션 | 없음 | Toss급 | Roomy ⭐ |
| 가격 | 무료 | ₩29,900 | Notion ○ |
| 자유도 | 높음 | 제한적 | Notion ○ |
| 받는 사람 UX | 투박함 | 예쁨 | Roomy ⭐ |

### 전략

**"공짜는 좋지만, 이건 예쁘고 부드럽다"**

- 가격대: 일회성 ₩29,900 (카페 3회분, 나이스 지수 높음)
- 메시지: "5분에 만드니까 시간 차이는 없고, 결과물은 훨씬 예쁘다"
- 대상: 디자인 감성 중시 호스트 (30~50대, 감성적)

## 경쟁자 2: Touch Stay 등 해외 가이드북 SaaS

### 특징

**예: Touch Stay, Guidebook, Airbnb 가이드 (내장 기능)**

**장점**
- 글로벌 수준의 완성도 높음
- 기능 풍부 (예: 자동 번역, 예약 연동)
- 인터랙션 괜찮음
- 가이드북 특화 섹션 많음
- 프리미엄 포지셔닝 (신뢰감)

**단점**
- 한국어 지원 부족
- 카톡 최적화 없음
- 한국 결제 수단 없음 (해외 카드 필수)
- 가격 높음 (월 $50 이상)
- UI가 영어 중심 (한국 사용자 불편)
- 현지 호스트 커뮤니티 부족
- 섹션 커스터마이즈 제한적

### Roomy의 우위

| 항목 | Touch Stay | Roomy | 우위 |
|-----|-----------|-------|------|
| 한국어 지원 | 부분 | 완전 | Roomy ⭐ |
| 카톡 최적화 | 없음 | 있음 | Roomy ⭐ |
| 한국 결제 | 없음 | 있음 | Roomy ⭐ |
| 가격 모델 | 월구독 $50+ | 일회 ₩29,900 | Roomy ⭐ |
| 디자인 감성 | 기업스러움 | 따뜻함 | Roomy ⭐ |
| 제작 시간 | 중간 | 5분 | Roomy ⭐ |
| 기능 풍부도 | 높음 | 적당함 | Touch Stay ○ |

### 전략

**"한국 시장 최적화"**

- 한국 호스트의 실제 니즈: "새벽 2시 카톡 질문 대응"
- 카톡 카드 최적화 (미리보기가 예쁨)
- 한국식 계좌 정보 (기존 업체에 없는 기능)
- 로컬 커뮤니티 (에어비앤비 호스트 커뮤니티 진입)
- 낮은 가격: 일회 ₩29,900 (월 $5 정도, Touch Stay의 1/10)

## 경쟁자 3: 국내 모바일 청첩장 업체

### 예: 바른손, 디어달리아, 페이퍼, 모닝더드 등

### 특징

**장점**
- 한국 시장 이해도 높음
- 대규모 사용자 베이스
- 결혼정보회사 연동
- 이미지 자산 풍부 (배경, 아이콘)
- 마케팅 파워 (TV 광고, 유명인 협력)
- 부가 기능 많음 (답장 관리, 축의금 통계 등)

**단점**
- 인터랙션이 낡음 (모션 부족)
- 템플릿 다양성은 많지만 디자인 감성은 평범함
- 제작 시간 오래 걸림 (UI 복잡)
- 가격 높음 (₩30,000~50,000)
- 디자인 트렌드 따라가지 못함
- 모바일 UX가 구식 (2015년 스타일)
- 특정 기능만 강점 (나머지는 떨어짐)

### Roomy의 우위

| 항목 | 바른손/디어달리아 | Roomy | 우위 |
|-----|---------|-------|------|
| 디자인 감성 | 평범함 | 높음 | Roomy ⭐ |
| 모션/인터랙션 | 낡음 | Toss급 | Roomy ⭐ |
| 제작 시간 | 20분+ | 5분 | Roomy ⭐ |
| 템플릿 다양성 | 많음 | 적당함 (처음) | 기존업체 ○ |
| 마케팅 | 강함 | 약함 | 기존업체 ○ |
| 가격 | ₩30,000~50,000 | ₩29,900 | Roomy ⭐ |
| 모바일 UX | 구식 | 현대적 | Roomy ⭐ |
| 감성/톤 | 기업스러움 | 따뜻함 | Roomy ⭐ |

### 전략

**"청첩장도, 객실 안내도, 다 예쁘고 빠르게"**

- 이미 청첩장 시장이 크다는 걸 인정: "그곳보다 낫다"로 돌파
- 수진·민준(예비부부) 페르소나: "바른손이랑 비슷하지만 훨씬 감성적"
- 객실 안내: "청첩장은 경쟁이 치열한데, 객실 안내는 시장이 공백 → 기회"

## Roomy의 차별화: "낫다" 3축

### 축 1: 감성 + 디자인

```
경쟁자들의 공통점:
- "충분히 기능한다" (하지만 예쁘지는 않음)
- "정보 전달이 된다" (하지만 느껴지는 프리미엄감 없음)
- "다 비슷해 보인다" (개성 없음)

Roomy:
- "한눈에 예쁘다" (첫 인상)
- "받는 사람이 '오'하며 감탄한다"
- "호스트가 자랑하고 싶어진다" (입소문 루프)
```

**증거**
- Noto Serif KR (세리프 폰트 = 고급감)
- 따뜻한 색상 팔레트 (신뢰감, 감정 전달)
- 절제된 화이트스페이스 (숨 쉬는 여백)
- 대조적 레이아웃 (핵심 요소만 튀어나옴)

### 축 2: Toss급 부드러운 사용감

```
경쟁자들:
- 정적 페이지 (스크롤해도 뭔가 움직임 없음)
- 버튼 누르면 딱 반응 (사람 손가락 같은 무게감 없음)
- 로딩 화면이 답답함 (진행 상황 모름)
- 세부사항 무시 (마이크로 인터랙션 없음)

Roomy:
- 섹션이 스크롤로 등장 (아래에서 위로 슬라이드)
- 버튼이 탄성 있게 반응 (spring 애니메이션)
- 댓글 제출 후 바로 추가됨 (즉시 피드백)
- 모든 클릭이 "느껴진다" (터치 감각)
```

**증거**
- Framer Motion spring 애니메이션 (기계적 아님)
- 모든 상호작용에 피드백 (토스트 메시지, 로딩 스피너)
- 60fps 성능 (버벅거리지 않음)
- 마이크로 인터랙션 (복사 버튼 토스트, 계좌 복사 피드백 등)

### 축 3: 5분 제작

```
경쟁자들:
- 필드가 너무 많음 (설정할 게 많음)
- UI가 복잡함 (어디를 눌러야 할지 모름)
- 옵션이 산재해 있음 (일관성 없음)
- 새로운 유저는 30분 걸림

Roomy:
- 꼭 필요한 필드만 (호스트 인터뷰로 검증)
- 좌우 분할 (왼쪽 입력 → 우측 미리보기)
- 모든 옵션이 한 화면에 (스크롤 최소)
- 새로운 유저도 5분 (직관적)
```

**증거**
- 섹션 on-off 체크박스 (add/remove 아님)
- 색상 선택 = 컬러 피커 하나 (팔레트 고민 없음)
- 사진은 drag-and-drop (복잡한 업로드 폼 아님)
- 텍스트 필드도 최소화 (요약만 입력)

**집행 방법**

## SWOT 분석

### Strengths (강점)
- 디자인 감성 + 인터랙션 (경쟁자 중 유일)
- 한국 시장 최적화 (카톡, 한국 계좌)
- 5분 제작 시간 (가장 빠름)
- 낮은 가격 (일회 ₩29,900)
- 2개 버티컬 (청첩장 + 객실 안내)

### Weaknesses (약점)
- 마케팅 파워 부족 (신생사)
- 템플릿 개수 적음 (처음: 2~3개)
- 브랜드 인지도 0 (처음부터)
- 사용자 커뮤니티 없음
- 기능 풍부도 낮음 (기본만 제공)

### Opportunities (기회)
- 모바일 청첩장 시장 성장세 (연 15% 성장)
- 에어비앤비 호스트 증가 (한국: 연 10% 증가)
- 감성 디자인 트렌드 (Z세대, MZ세대)
- 모바일 우선 콘텐츠 (PC 청첩장은 감소)
- 로컬 SaaS 기회 (한국 특화)

### Threats (위협)
- 기존 업체 기능 모방 가능 (6개월 내)
- 대기업 진입 (카카오, 라인, 당근마켓)
- 무료 대체재 계속 존재 (Notion, 카톡)
- 경기 침체 시 구매력 감소
- 결혼 인구 감소 추세
